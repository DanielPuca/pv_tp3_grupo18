# Gestión de Proyectos

Este proyecto fue desarrollado con React y permite administrar una lista de proyectos de manera dinámica.

La aplicación permite:
- Agregar nuevos proyectos
- Visualizar proyectos registrados
- Buscar proyectos por título
- Eliminar proyectos de la lista

En el desarrollo se trabajó con componentes, useState, renderizado dinámico, manejo de eventos y organización del código utilizando servicios y componentes reutilizables.
